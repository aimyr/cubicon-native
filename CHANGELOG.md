# Changelog

## 0.1.0

First source release of the native Mac workflow for Cubicon Single Plus and Style Plus A15.

- Swift/AppKit interface and SceneKit model/toolpath preview.
- STL and OBJ import, model transforms and printable-volume validation.
- Manufacturer-authored printer profiles and PLA/ABS/PETG settings.
- Native CuraEngine integration, asynchronous slicing and G-code export.
- Swift settings-expression resolver and native command-line workflow.
- Reproducible build, project artwork and ARM64 GitHub Actions verification.

File generation is verified; physical printing and direct device control remain outside this release's validated scope.
